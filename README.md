# Industrial Asset Health Guardian
A Software-in-the-Loop (SIL) Digital Twin architecture for predictive maintenance. 

**Key Technologies:**
* **Edge AI:** Scikit-learn Isolation Forest for multi-variable anomaly detection.
* **Immutable Auditing:** SHA-256 cryptographic hash chain to secure failure logs.
* **Cloud Sync:** Live data pipelining to Google Firebase Realtime Database.
* **Predictive Maintenance:** Remaining Useful Life (RUL) degradation curves.
